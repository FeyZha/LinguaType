# 表达库规格

## Requirements

### Requirement: 表达库必须保存可复用表达资产

表达库必须保存用户显式确认后的可复用表达资产，并支持搜索、筛选、收藏、复制、插入、删除和 JSON 导出。

#### Scenario: 用户保存表达

- **GIVEN** 用户显式应用了当前句建议或保存选中文本
- **WHEN** 应用提取到有效表达
- **THEN** 表达写入 `linguatype.learningLibrary.v1`
- **AND** 空内容或无意义条目不得保存

### Requirement: 表达库必须按类型和难度组织

表达库不得再按写作模式展示或筛选表达。表达条目必须支持难度 1-5，并以低打扰 tag 显示。

#### Scenario: 用户筛选难度

- **GIVEN** 表达库存在多个不同难度条目
- **WHEN** 用户选择难度 3
- **THEN** 表达库只显示难度为 3 的条目
- **AND** 页面不按写作模式过滤表达

#### Scenario: 用户查看表达条目

- **GIVEN** 表达库条目存在难度信息
- **WHEN** 页面展示该条目
- **THEN** 条目标题附近显示精致小难度 tag
- **AND** 条目不显示 `当前模式` 或 `Natural` 等写作模式关联文案

### Requirement: 个人词典必须作为表达库类型管理

个人词典不得作为独立导航功能出现，必须整合到表达库的类型视图中。

#### Scenario: 用户管理个人词典

- **GIVEN** 用户进入表达库页面
- **WHEN** 用户选择 `个人词典` 类型
- **THEN** 页面展示个人词典管理入口
- **AND** 词条仍写入 `linguatype.personalDictionary.v1`

### Requirement: 表达库必须采用去卡片化沉浸组织

表达库页面必须减少卡片网格和硬边框，优先使用文档流、分组行或轻列表。

#### Scenario: 用户进入表达库

- **GIVEN** 用户点击左侧 `表达库`
- **WHEN** 表达库页面展示
- **THEN** 表达条目以自然列表或分组行展示
- **AND** 页面不使用大面积卡片网格作为主要组织形式

### Requirement: 表达库必须支持写作中的表达复现提示

当用户在正文中自然写出表达库中已沉淀的高价值表达或可识别变体时，系统必须以低打扰方式在原文位置提示一次，强化用户已经复现该表达的学习印象。

#### Scenario: 用户写出已学表达

- **GIVEN** 表达库中存在类型为 `phrase` 或 `collocation` 的高价值表达
- **WHEN** 用户正文中出现该表达或本地规则可识别的变体
- **THEN** 写作区在对应文本上显示一次极简复现动效
- **AND** 不调用 LLM
- **AND** 不修改正文
- **AND** 不保存新的学习数据

#### Scenario: 用户查看复现说明

- **GIVEN** 写作区存在表达复现提示
- **WHEN** 用户 hover 或键盘 focus 该提示
- **THEN** 系统显示轻量说明，表明这是表达库命中
- **AND** 说明可包含标准表达、释义和来源
- **AND** 视觉形式不得复用 AI 修改入口或文本校对 tag

#### Scenario: 系统避免过度提示

- **GIVEN** 一句话中存在多个表达库命中
- **WHEN** 系统计算复现提示
- **THEN** 同一句最多展示一个提示
- **AND** 普通单词、过短表达和个人词典条目不得触发复现提示
