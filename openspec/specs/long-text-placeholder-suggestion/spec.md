# Long Text Placeholder Suggestion 规格

## Requirements

### Requirement: 主写作区必须支持单块长文本正文

主写作区 MUST 以一个连续、可编辑的长文本正文为核心输入面，而不是按大纲拆成多个正文输入卡片。

#### Scenario: 用户连续输入长文本

- **WHEN** 用户在写作页正文中输入、删除、换行或移动光标
- **THEN** 编辑器 MUST 保持类似 Word、Typora、飞书文档的自然文本输入体验
- **AND** 新输入内容 MUST 出现在当前光标位置
- **AND** 不得默认插入到段落开头
- **AND** 标题、领域和正文 MUST 视觉对齐清晰，正文排版遵从设计文档

#### Scenario: 大纲功能退出主写作链路

- **WHEN** 用户进入主写作页
- **THEN** 页面 MUST 不再把大纲作为正文输入结构
- **AND** 不得显示独立的大纲管理卡片
- **AND** 写作状态栏 MUST 固定在写作页最底部，不受内联卡片、浮层或后台任务影响

### Requirement: 中文片段必须被视为表达占位符

应用 MUST 把用户写作中的中文片段理解为英文表达卡住时的自然占位符，而不是即时错误。

#### Scenario: 用户刚输入中文片段

- **WHEN** 用户在未完成句子中输入中文片段
- **THEN** 应用 MUST 不调用 `/api/enhance-fast`
- **AND** 不得显示弹窗、卡片或会打断写作的提示
- **AND** 可以在本地记录该句包含中文占位，但不得把它当成校对错误

#### Scenario: 用户写完包含中文的句子

- **WHEN** 用户输入句号、问号、感叹号、换行、按 Ctrl/Cmd + Enter，或停顿达到稳定阈值
- **AND** 当前稳定句包含中文
- **THEN** 应用 MAY 后台异步调用 `/api/enhance-fast`
- **AND** 只处理该句
- **AND** 不得自动替换正文
- **AND** 不得生成整段、续写或改变用户论点

### Requirement: 应用必须在句子稳定后建议当前句

AI 建议 MUST 只在完整句子稳定后触发，且保持非阻塞。

#### Scenario: 后台自动检测中文句子

- **WHEN** 正文中存在一个或多个包含中文的稳定句
- **THEN** 应用 MAY 为这些句子异步准备建议
- **AND** 写作区 MUST 仍可继续输入、选择和编辑文本
- **AND** 失败、加载或等待状态不得占据正文下方的常驻区域

#### Scenario: 快捷键调用当前句

- **WHEN** 用户按配置的快捷键
- **THEN** 应用 MUST 针对光标所在句调用建议逻辑
- **AND** 仍然遵守范围捕获、冲突检测和用户显式采纳规则

### Requirement: 中文占位建议必须先以句旁轻提示呈现

AI 建议准备好后 MUST 先以不打断写作的轻提示出现，而不是立即展开卡片。

#### Scenario: 建议准备完成

- **WHEN** 某个目标句已有可用建议
- **THEN** 应用 MUST 在该句同一水平附近的右侧空白处显示小图标
- **AND** 图标 MUST 对齐目标句，不得漂移到无关文本
- **AND** 正文中不得显示打扰写作的虚线、边框或常驻说明文案

#### Scenario: 用户点击句旁图标

- **WHEN** 用户点击目标句旁的小图标
- **THEN** 目标句 MUST 临时单独成为一段
- **AND** 其他正文内容 MUST 顺势排版
- **AND** 内联卡片 MUST 紧跟目标句下方
- **AND** 卡片不得重复显示与目标句完全相同的原文标题或说明

#### Scenario: 用户点击已处理句子

- **WHEN** 用户再次点击曾调用过建议的句子或相关轻提示
- **THEN** 应用 SHOULD 能重新打开对应内联卡片供复习或换一种表达
- **AND** 不得破坏普通光标定位和继续输入体验

### Requirement: 采纳后必须沉淀表达资产

用户明确采纳建议后，系统 MUST 只替换目标句，并在后台保存表达学习资产。

#### Scenario: 用户采纳建议

- **WHEN** 用户点击采纳或按 Tab 采纳
- **THEN** 应用 MUST 用建议句替换原目标句
- **AND** 替换后目标句 SHOULD 回到原本正文排布
- **AND** 对应内联卡片记录 MUST 保留，以便后续复习
- **AND** 学习资产 MUST 通过既有采纳后提取链路保存
- **AND** 表达库侧边导航 SHOULD 显示未查看更新标识

#### Scenario: 用户查看已采纳卡片

- **WHEN** 用户打开已采纳句子的内联卡片
- **THEN** 卡片 MUST 更简洁
- **AND** 不得显示忽略或采纳按钮
- **AND** SHOULD 只保留换一种表达等复习相关操作

### Requirement: 选区操作必须使用轻量功能条

写作页选中内容后 MUST 使用跟随选区的轻量功能条，不再显示单独小图标。

#### Scenario: 用户选中正文内容

- **WHEN** 用户在正文中选中一段文本
- **THEN** 应用 MUST 在选区附近显示轻量功能条
- **AND** 功能条 SHOULD 包含解释、保存到表达库、复制等符合产品核心体验的操作
- **AND** 蓝色选区样式 MUST 与写作页设计一致
- **AND** 功能条不得遮挡关键文本或破坏选区

### Requirement: 写作习惯趋势必须可读

写作习惯页 MUST 正常显示图表内容，并与页面其他动效保持一致。

#### Scenario: 有趋势数据

- **WHEN** 写作习惯存在近 7 天修正记录
- **THEN** 趋势图 MUST 显示可见柱状或刻度内容
- **AND** 不得只显示空线

#### Scenario: 数据为空

- **WHEN** 写作习惯没有可统计数据
- **THEN** 页面 MUST 显示轻量空状态
- **AND** 动效 MUST 与列表内容的进入动效统一
