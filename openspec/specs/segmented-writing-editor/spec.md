# 分段写作编辑器规格

## Requirements

### Requirement: 主写作界面必须按大纲显示段落输入框

进入主写作界面后，应用必须根据大纲点数量展示对应数量的段落输入框。

#### Scenario: 用户有 3 个大纲点

- **GIVEN** Writing Setup 中有 3 个大纲点
- **WHEN** 用户进入主写作界面
- **THEN** 主界面显示 3 个段落输入框
- **AND** 每个输入框前显示对应大纲点

### Requirement: 用户必须能在主界面编辑大纲

用户必须能在主写作界面编辑大纲点，并增减大纲数量。

#### Scenario: 用户编辑大纲点

- **GIVEN** 用户在主写作界面
- **WHEN** 用户修改某个大纲点
- **THEN** 对应段落输入框前的提示同步更新
- **AND** 大纲修改保存到本地

#### Scenario: 用户增加大纲点

- **GIVEN** 用户在主写作界面
- **WHEN** 用户添加一个大纲点
- **THEN** 应用新增一个对应段落输入框

#### Scenario: 用户减少大纲点

- **GIVEN** 用户在主写作界面
- **WHEN** 用户删除一个大纲点
- **THEN** 应用同步处理对应段落输入框
- **AND** 不应无提示丢弃已有段落文本

### Requirement: 分段写作不得破坏最新句增强

分段写作必须保持 latest-sentence enhancement 只处理用户已写出的最新非空句。

#### Scenario: 用户在某段中触发增强

- **GIVEN** 用户聚焦某个段落输入框
- **WHEN** 用户触发增强
- **THEN** 应用只处理当前用户文本中的最新非空句
- **AND** 不改写其它段落
- **AND** Apply/Cancel 规则保持不变

### Requirement: Draft 必须保存和恢复分段内容

分段写作内容必须继续本地自动保存并能恢复。

#### Scenario: 用户刷新页面

- **GIVEN** 用户已经在多个段落输入框中写入内容
- **WHEN** 应用重新加载
- **THEN** 应用恢复每个段落的文本
- **AND** 大纲点和段落文本仍然对应
