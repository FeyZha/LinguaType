# 分段写作编辑器规格

## Requirements

### Requirement: 主写作界面必须按大纲显示段落正文块

进入主写作界面后，应用必须根据大纲点数量显示对应数量的段落正文块。段落输入应表现为 Typora 式 `contentEditable` 文档表面，而不是独立 textarea 卡片列表。

#### Scenario: 用户有 3 个大纲点

- **GIVEN** Writing Setup 中有 3 个大纲点
- **WHEN** 用户进入主写作界面
- **THEN** 主界面显示 3 个对应段落正文块
- **AND** 每个段落正文块前显示对应大纲点
- **AND** 大纲点以文档标题或段落标题风格融入正文流
- **AND** 段落正文块不得依赖重边框、强背景或 shadow 来区分层级

### Requirement: 分段写作不得破坏最新句增强

分段写作必须保持 latest-sentence enhancement 只处理用户已写出的最新非空句。

#### Scenario: 用户在某段中触发增强

- **GIVEN** 用户聚焦某个段落正文块
- **WHEN** 用户触发增强
- **THEN** 应用只处理当前完整文本中的最新非空句
- **AND** 不改写其它段落
- **AND** Apply/Cancel 规则保持不变
- **AND** Apply 仍使用 captured range 进行替换

### Requirement: Draft 必须保存和恢复分段内容

分段写作内容必须继续本地自动保存并能恢复。Typora 式视觉不得改变底层文本模型。

#### Scenario: 用户刷新页面

- **GIVEN** 用户已经在多个段落正文块中写入内容
- **WHEN** 应用重新加载
- **THEN** 应用恢复每个段落的文本
- **AND** 大纲点和段落文本仍然对应
- **AND** 底层 draft 仍以单个文本值保存
- **AND** 段落之间仍通过空行分隔

### Requirement: 大纲默认必须处于锁定状态

主界面中的大纲默认只读展示。用户必须明确进入修改状态后才能编辑大纲。

#### Scenario: 用户未点击修改大纲点

- **GIVEN** 用户位于主写作界面
- **WHEN** 用户查看段落标题的大纲点
- **THEN** 大纲点以只读提示展示
- **AND** 不显示可直接编辑的大纲输入框

#### Scenario: 用户点击单个大纲点编辑入口

- **GIVEN** 用户位于主写作界面
- **WHEN** 用户点击某个段落标题旁的大纲编辑入口
- **THEN** 仅该大纲点进入内联编辑态
- **AND** 其他大纲点保持只读展示
- **AND** 应用不展开 Writing Setup 抽屉

### Requirement: 用户必须能在内联状态下增减大纲点

用户必须能在主写作界面通过低调的内联入口增减大纲点。删除已有正文的段落不得导致无提示丢失文本。

#### Scenario: 用户增加大纲点

- **GIVEN** 用户在主写作界面
- **WHEN** 用户添加一个大纲点
- **THEN** 应用新增一个对应段落正文块
- **AND** 正文底层文本模型仍保持单个 draft 文本

#### Scenario: 用户删除空段落对应的大纲点

- **GIVEN** 用户在主写作界面
- **AND** 目标大纲点对应段落没有正文
- **WHEN** 用户删除该大纲点
- **THEN** 应用删除该大纲点和对应空段落

#### Scenario: 用户删除已有正文段落对应的大纲点

- **GIVEN** 用户在主写作界面
- **AND** 目标大纲点对应段落已有正文
- **WHEN** 用户尝试删除该大纲点
- **THEN** 应用阻止删除
- **AND** 应用提示用户先清空对应段落正文
