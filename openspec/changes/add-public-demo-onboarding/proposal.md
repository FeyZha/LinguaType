# 变更提案：公开体验版欢迎页与部署准备

## 背景

LinguaType 准备作为正式版本上传 GitHub 并通过 Vercel 提供公开体验。新访客需要先理解产品定位、核心能力和最短体验路径，而不是直接面对空白编辑器。同时公开体验版需要支持部署侧 API Key，避免把真实密钥写入 GitHub 或下发到浏览器。

## 目标

- 增加首访欢迎页和开屏动画，使用现有 logo / icon 资产，中文优先说明产品定位、核心价值、核心功能和使用方法。
- 写作存档首次初始化时内置一篇完整示例文档，覆盖中英混写、英文润色、段落检查和文章地图体验入口。
- 支持 Vercel 环境变量中的服务端 API Key，公开体验版可直接请求模型，但 GitHub 不保存真实 key。
- README 收敛为 GitHub 浏览者需要的信息：产品简介、本地运行、Vercel 环境变量、隐私与边界。

## 非目标

- 不新增登录、数据库、云同步、支付或导入系统。
- 不把欢迎页变成聊天入口、作文生成器或全文改写入口。
- 不自动改写示例文档，不自动保存学习数据。
- 不提交真实 API Key。
