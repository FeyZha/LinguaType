# Long Text Placeholder Suggestion 规格变更

## ADDED Requirements

### Requirement: 主写作区必须支持单块长文本正文

主写作区正文必须以一整块可连续输入的长文本区域呈现，不得再按大纲点拆成多个正文输入块。

#### Scenario: 用户进入主写作区

- **GIVEN** 用户已经进入主写作界面
- **WHEN** 主写作区显示正文编辑器
- **THEN** 应用显示一个连续的正文原生 `textarea` 写作区域
- **AND** 正文区域不显示 `第 N 段自由写作`
- **AND** 正文区域不显示 outline heading
- **AND** 底层正文仍保存为单个 `text` 字符串
- **AND** 文章标题与正文写作区域左边界对齐

### Requirement: 中文片段必须被视为表达占位符

用户在英文句子中输入中文片段时，应用必须把该中文片段视为表达占位符，而不是错误。

#### Scenario: 用户刚输入中文片段

- **GIVEN** 用户正在正文中输入英文句子
- **WHEN** 用户输入中文片段但句子尚未稳定
- **THEN** 应用可以显示轻量视觉提示
- **AND** 应用不得立即调用 LLM
- **AND** 应用不得自动替换中文片段
- **AND** 应用不得把该片段显示为本地校对错误

### Requirement: 应用必须在句子稳定后建议当前句

当含中文占位符的当前句稳定后，应用必须只针对该句请求建议。

#### Scenario: 用户完成含中文占位符的句子

- **GIVEN** 当前句包含中文占位符
- **WHEN** 用户输入句号、问号、感叹号、换行
- **THEN** 应用不得立即调用 LLM
- **AND** 应用必须等待当前完整句稳定 800ms
- **WHEN** 当前完整句稳定 800ms
- **THEN** 应用调用当前句建议逻辑
- **AND** 请求只包含该当前句作为待处理句子
- **AND** 应用不得处理全文或其他句子
- **AND** 请求运行时不得在写作区显示加载弹窗、加载条或文档流占位块

#### Scenario: 用户输入未完成的中文占位句

- **GIVEN** 当前句包含中文占位符
- **AND** 当前句尚未输入句子边界
- **WHEN** 用户停止输入 800ms
- **THEN** 应用只保留轻量提示
- **AND** 应用不得调用 LLM

#### Scenario: 用户写纯英文句子

- **GIVEN** 当前句不包含中文占位符
- **WHEN** 用户输入句子边界或停止输入
- **THEN** 应用不得自动调用 LLM

### Requirement: 中文占位建议必须先以句旁轻提示呈现

当前句建议必须靠近正文以内联卡片呈现，不得用弹窗、聊天面板或右侧建议栏打断写作。

#### Scenario: 建议生成成功

- **GIVEN** 应用已获得当前句建议
- **WHEN** 建议尚未被用户打开
- **THEN** 应用只在问题句右侧空白处显示一个轻量图标
- **AND** 图标与问题句保持同一水平线
- **AND** 应用不得在正文上显示虚线、边框或整句下划线
- **AND** 应用不得自动展开建议卡片

#### Scenario: 用户打开建议

- **GIVEN** 问题句右侧显示建议图标
- **WHEN** 用户点击该图标
- **THEN** 问题句临时成为独立焦点句
- **AND** 建议卡紧跟显示在该句下方
- **AND** 卡片不得再次显示与焦点句完全相同的完整原句
- **THEN** 卡片显示自然英文句子
- **AND** 卡片显示 `中文表达 -> 英文表达`
- **AND** 卡片显示一个可复用结构
- **AND** 卡片提供采纳、忽略、换一种说法操作

#### Scenario: 用户查看中文意群对应关系

- **GIVEN** 建议卡已经打开
- **AND** 焦点句中存在中文占位意群
- **WHEN** 用户点击或悬停中文意群
- **THEN** 应用高亮英文建议句中对应的英文表达
- **AND** 应用高亮学习点中的对应英文表达
- **AND** 若中文占位覆盖整句，学习点必须收缩到核心表达单元

#### Scenario: 用户处理建议后再次查看

- **GIVEN** 用户已经采纳或忽略过某条当前句建议
- **WHEN** 建议卡关闭
- **THEN** 句子回到原本正文位置
- **AND** 应用保留该句右侧的低干扰复习入口
- **WHEN** 用户点击该复习入口
- **THEN** 应用重新打开该句对应的内联建议卡

### Requirement: 采纳后必须沉淀表达资产

用户采纳中文占位建议后，应用必须保存短学习点到本地表达库。

#### Scenario: 用户采纳建议

- **GIVEN** 当前建议来自含中文占位符的句子
- **AND** 当前 editor text 与 snapshotFullText 一致
- **WHEN** 用户采纳建议
- **THEN** 应用只替换 captured sentence range
- **AND** 应用保存英文表达单元到 `linguatype.learningLibrary.v1`
- **AND** 学习资产包含中文表达、英文表达和可复用结构

#### Scenario: 用户忽略建议

- **GIVEN** 当前建议已经显示
- **WHEN** 用户忽略建议
- **THEN** 应用关闭建议
- **AND** 不修改正文
- **AND** 不保存 Learning Library 或 Correction Events

### Requirement: 选区操作必须使用轻量功能条

选中文本后，应用必须显示贴近选区的轻量功能条，不得只显示一个需要二次理解的小图标。

#### Scenario: 用户选中英文表达

- **GIVEN** 用户在正文中选中英文内容
- **WHEN** 选区有效
- **THEN** 应用显示选中文本功能条
- **AND** 功能条提供解释、保存到表达库、复制、关闭
- **AND** 功能条不得提供选区改写或自动替换

### Requirement: 写作习惯趋势必须可读

写作习惯页面的近 7 天修正节奏不得呈现为空白图表。

#### Scenario: 写作习惯有修正数据

- **GIVEN** 本地存在 Correction Events
- **WHEN** 用户打开写作习惯页面
- **THEN** 近 7 天修正节奏显示可见柱状内容
- **AND** 显示对应日期和次数

#### Scenario: 写作习惯没有修正数据

- **GIVEN** 本地没有 Correction Events
- **WHEN** 用户打开写作习惯页面
- **THEN** 趋势区域显示轻量空状态
