# learning-library Delta

## ADDED Requirements

### Requirement: 表达库必须支持写作中的表达复现提示

当用户在正文中自然写出表达库中已沉淀的高价值表达或可识别变体时，系统必须以低打扰方式在原文位置提示一次，强化用户已经复现该表达的学习印象。

#### Scenario: 用户写出已学表达

- **GIVEN** 表达库中存在类型为 `phrase` 或 `collocation` 的高价值表达
- **WHEN** 用户正文中出现该表达或本地规则可识别的变体
- **THEN** 写作区在对应文本上显示一次极简复现动效
- **AND** 不调用 LLM
- **AND** 不修改正文
- **AND** 不保存新的学习数据

#### Scenario: 用户查看复现说明

- **GIVEN** 写作区存在表达复现提示
- **WHEN** 用户 hover 或键盘 focus 该提示
- **THEN** 系统显示轻量说明，表明这是表达库命中
- **AND** 说明可包含标准表达、释义和来源
- **AND** 视觉形式不得复用 AI 修改入口或文本校对 tag

#### Scenario: 系统避免过度提示

- **GIVEN** 一句话中存在多个表达库命中
- **WHEN** 系统计算复现提示
- **THEN** 同一句最多展示一个提示
- **AND** 普通单词、过短表达和个人词典条目不得触发复现提示
