# 变更提案：优化写作区缓存、校对提示与文案体系

## 背景

当前写作页面在重新打开已有文档时，可能重新触发中文占位句建议请求，导致已经生成过的 AI 修改结果没有被复用。写作区正文排版、校对提示、底部状态栏和低频页面文案也存在不一致：校对 tag 有重叠和重阴影问题，提示与原文位置关联弱，文本校对详情面板与 tag 形态重复，部分页面仍保留装饰性中英文并排标签。

## 目标

1. 已生成过的当前句建议按本地文档、原句、模式、强度和领域缓存；重新打开页面时优先复用本地结果，不因页面加载重复调用 `/api/enhance-fast`。
2. 写作区正文排版按 `DESIGN.md` 的编辑器优先原则重做，提升字体、行距、宽度和留白质量。
3. 本地校对从弹出详情面板改为写作区轻量 tag 与底部字词统计组合。
4. 校对 tag 指向具体文本位置，hover/focus 时高亮对应问题片段。
5. 模式、强度等状态栏菜单回到轻量下拉形态，统一点击外部和 Esc 收起逻辑。
6. 清理用户界面的装饰性中英文并排文案，改为中文主文案；仅在 API、JSON、localStorage 等必要技术名词中保留英文。

## 非目标

- 不改变最新句增强的 Apply / Cancel 门控。
- 不引入登录、数据库、云同步或服务端持久化。
- 不把本地校对升级为全文批改、作文评分或自动改写。
- 不新增常驻右侧管理栏。
