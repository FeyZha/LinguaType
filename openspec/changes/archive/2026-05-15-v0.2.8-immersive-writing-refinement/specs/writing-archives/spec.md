# writing-archives 规格增量

## ADDED Requirements

### Requirement: 写作存档必须支持搜索、排序、筛选和领域堆栈

写作存档侧边栏必须在不增加管理面板感的前提下，支持用户快速定位和组织本地文章。

#### Scenario: 用户搜索文章
- **GIVEN** 本地存在多个写作存档
- **WHEN** 用户在侧边栏输入搜索关键词
- **THEN** 侧边栏仅显示标题或摘要匹配的文章

#### Scenario: 用户按修改时间排序
- **GIVEN** 本地存在多个写作存档
- **WHEN** 用户选择按修改时间由近到远排序
- **THEN** 文章列表按 `updatedAt` 倒序显示

#### Scenario: 用户拖动文章进入领域堆栈
- **GIVEN** 文章 A 当前属于 `自定义`
- **WHEN** 用户将文章 A 拖入 `教育` 堆栈
- **THEN** 文章 A 的领域保存为 `教育`
- **AND** 文章 A 标记为用户手动分类
- **AND** 后续自动领域分类不得覆盖文章 A

### Requirement: 领域自动分类必须低频且可被用户覆盖

系统只能在用户切换文章时，且满足阈值条件后，低频调用模型进行领域分类。

#### Scenario: 文章不满足分类条件
- **GIVEN** 当前文章字数不足或内容变化不足 40%
- **WHEN** 用户切换到另一篇文章
- **THEN** 系统不得调用领域分类 API

#### Scenario: 文章已被用户手动分类
- **GIVEN** 当前文章存在用户手动分类标记
- **WHEN** 用户切换到另一篇文章
- **THEN** 系统不得调用领域分类 API
