# 将表达菜单入口替换为检查本段

## 背景

当前 `Ctrl/Cmd + K` 会打开 Inline Expression Menu，菜单里同时包含本地模板、表达库插入和“检查本段”。这让高频写作入口承担了多个低频意图，也让用户需要先打开弹窗再进入段落流畅度检查。

## 目标

- 删除表达菜单弹窗和对应触发设置。
- 将 `Ctrl/Cmd + K` 直接绑定到“检查本段”。
- 在折叠侧边栏顶部快捷区增加“检查本段”图标按钮。
- 保留段落流畅度检查的现有结果、diff、Apply/Cancel 和冲突检测。
- 保留表达库页面和 Selection Actions 的保存/解释/复制能力。

## 非目标

- 不新增全文流畅度检测。
- 不让段落流畅度检查自动应用。
- 不删除表达库数据、表达库页面或选区保存到表达库。
- 不改变 `/api/check-paragraph-flow` 的返回结构。
