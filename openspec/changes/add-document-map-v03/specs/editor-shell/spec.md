# Editor Shell Spec Delta

## ADDED Requirements

### Requirement: 主写作页必须提供文章地图入口

主写作页必须在编辑器附近提供“检查文章地图”入口，让用户手动生成全文结构地图。入口不得取代当前句增强、检查本段或正文输入。

#### Scenario: 用户查看主写作页

- **GIVEN** 用户已经进入主写作页
- **WHEN** 页面展示写作工作台
- **THEN** 用户可以找到“检查文章地图”
- **AND** 正文编辑器仍是主视觉和主输入面
- **AND** 页面不显示右侧常驻文章地图管理栏

### Requirement: 文章地图面板不得拆分正文输入

文章地图面板可以在编辑器附近或中间主舞台打开，但正文必须继续保持一个连续长文本输入面。宽屏时应优先使用左右对照布局，让文章地图和正文编辑器同时可见；窄屏可以回退为上下排列。应用不得把正文转换为大纲卡片或按段落生成多个输入块。

#### Scenario: 用户打开文章地图面板

- **GIVEN** 用户在主写作页点击“检查文章地图”
- **WHEN** 文章地图展示
- **THEN** 面板以可折叠大纲方式展示结构信息
- **AND** 宽屏下页面展示“文章地图对照区”，让地图和正文编辑器左右同时可见
- **AND** 文章地图栏和原文对照栏各自独立滚动且不显示可见滚动条
- **AND** 用户滚动原文对照栏时不得带动文章地图栏位置
- **AND** 段落节点中的“查看建议”只展开轻量段落健康建议，不触发段落流畅度检查
- **AND** 轻量段落健康建议显示在当前段落卡片内，不显示右下角独立浮层
- **AND** 点击“检查本段”后，文章地图面板进入“本段检查”二级界面并显示运行中动效
- **AND** 正文仍在同一页面保留为连续 textarea 写作面
- **AND** 应用不按段落拆分正文输入

### Requirement: 文章地图交互必须中文优先且低打扰

文章地图相关按钮、状态、空状态、错误和节点状态必须使用中文优先文案，并保持轻量检查面板风格，不得变成大型 dashboard 或聊天界面。

#### Scenario: 文章地图处于不同状态

- **GIVEN** 用户操作文章地图
- **WHEN** 页面展示加载、成功、过期、空状态或错误
- **THEN** 文案使用中文优先
- **AND** 加载中可显示“正在整理文章结构……”
- **AND** 过期时可显示“正文已修改，当前文章地图可能不是最新结果。”
- **AND** 错误时可显示“文章地图生成失败，请检查 API 设置后重试。”
