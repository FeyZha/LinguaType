# OpenSpec

本目录保存 LinguaType 的变更提案、设计、任务和规格更新。

非平凡产品或实现变化遵循：

1. 使用 `/opsx:propose "<change summary>"` 创建 change。
2. 检查 `openspec/changes/<change-name>/` 中的 proposal、design 和 tasks。
3. 确认 change 与 `AGENTS.md`、`docs/PRODUCT-REASONING.md` 一致后再实现。
4. 完成最小验证后使用 `/opsx:archive` 归档。

OpenSpec 不得替代当前产品推导，也不得提前把尚未验证的假设写成确定需求。
