# QA Acceptance Skill

Before considering a change complete, verify:

1. Latest sentence extraction works.
2. Ctrl/Cmd + J triggers enhancement.
3. Empty editor does not call API.
4. Missing API settings opens settings or shows a helpful error.
5. Mixed Chinese-English sentence is converted and polished.
6. Pure English sentence is lightly polished.
7. Multiple Chinese segments in the latest sentence are all converted.
8. Earlier sentences are not rewritten.
9. Previous context is used only for tone/coherence.
10. Diff is generated by code.
11. Apply replaces only the latest sentence.
12. Cancel changes nothing.
13. Learning items are saved only after Apply.
14. Invalid JSON response is handled safely.
15. npm run lint passes.
16. npm run build passes.
