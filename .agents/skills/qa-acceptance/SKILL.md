# QA Acceptance Skill

Before considering a change complete, run:

```bash
npm test
npm run lint
npm run build
```

## Acceptance Coverage

Verify:

1. Latest sentence extraction works.
2. `Ctrl/Cmd + Enter` triggers enhancement by default.
3. `Ctrl/Cmd + J` works only in legacy trigger mode and prevents browser default behavior.
4. Empty editor does not call the API.
5. Missing API settings opens settings or shows a helpful error unless Mock Mode is enabled.
6. Mixed Chinese-English latest sentence is converted and polished.
7. Pure English sentence is lightly polished, and unchanged output is valid.
8. Multiple Chinese segments in the latest sentence are all converted.
9. Earlier sentences are not rewritten.
10. Duplicate earlier sentences do not cause the wrong sentence to be replaced.
11. Previous context is used only for tone, meaning, and coherence.
12. Diff is generated by code.
13. Apply replaces only the captured latest-sentence range.
14. Cancel, Copy, Regenerate, and Close do not save learning data.
15. Background learning extraction runs only after Apply.
16. Learning Library deduplicates by type and normalized content.
17. Correction Events aggregate into Writing Habits.
18. Paragraph Health trigger modes, cache, and throttle behavior work.
19. Inline Expression Menu is local by default.
20. Selection Actions explain or save selected text only; they do not rewrite selected text.
21. Mock Mode requires no Base URL, API Key, or Model.
22. API key redaction works.
23. Invalid model JSON is handled safely, including common Markdown code fences.
24. User-facing UI text is Chinese-first while key feature names remain English or bilingual.
