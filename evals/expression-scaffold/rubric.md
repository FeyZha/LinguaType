# 判断标准

本文件只说明什么样的输出算好或算错，不规定具体分数。

## Judge 可见数据

首轮 LLM Judge 可以看到：

```text
task_prompt
full_essay
target_sentence
segments.source_zh
segments.intent_zh
must_not_add
system_output
```

首轮评分不提供 `slot_function` 和 `span_scope`。Judge 应根据中文片段、目标句位置和语境直接判断；评分完成后再按 `case_id` 合并分类字段做切片统计。

## 1. 语义正确性

判断问题：

- 是否理解每处中文在题目、全文和目标句中的真实含义？
- 是否覆盖全部中文片段？
- 是否保持用户原来的观点和立场？
- 是否避开 `must_not_add` 所列内容及其他原文没有表达的新增观点？

`must_not_add` 是常见误解示例，不是允许新增其他内容的白名单。

若实际输出在本维度得分较低，复盘时可优先检查 L4 的上下文理解或提示约束，但仍需依据实际输出确认原因。

## 2. 表达支架质量

判断问题：

- 英文表达是否自然，适合 IELTS Task 2 书面语境？
- 输出粒度是否与原中文片段的结构大小相符？
- 输出是否能接入中文片段在目标句中承担的语法位置？
- 是否每处只提供一个表达？
- 是否只替换中文片段，而没有重写完整 `target_sentence`？

若实际输出在本维度得分较低，复盘时可优先检查 L4 的生成要求或 L5 的输出限制，但仍需依据实际输出确认原因。

## 3. 用户可继续性

判断问题：

- 用户看到支架后，能否自己继续完成目标句？
- 是否无需再次搜索或请求完整答案？
- 是否只需很小的语言调整，而不是重写整句？

LLM Judge 对这一维度只能做离线代理判断，最终仍需人工校准，不能写成真实用户行为。

## 硬失败

出现以下任一情况，直接视为 bad case：

- 新增用户没有表达的观点；
- 改变用户立场；
- 遗漏任一中文片段；
- 输出重写后的完整 `target_sentence`；
- 为同一中文返回多个候选；
- `sourceZh` 未原样对应中文片段，或多项结果顺序错误；
- 字段缺失或输出无法解析。

中文片段本身是分句时，返回对应大小的英文分句不自动构成硬失败。

## 不在首版评测范围内

- 全文质量或 IELTS 分数；
- 用户最终句子的全部语法问题；
- 写作速度、满意度、留存或长期学习效果；
- `reusableStructure`、`structureMeaningZh` 等尚未进入使用链路的结构资产。
