# DeepSeek Prompt v5 定向复测结果

## 结论

Prompt v5 已消除这 9 个目标 case 的硬协议失败：从 v4 的 6/9 提升为 9/9。冻结帮助策略动作一致从 3/9 变为 6/9。该结果说明显式提供顶层中文片段能稳定处理范围，但不能证明人工效果已经改善；v5 回复仍需用户逐条审核。

## 同一批 9 case 对照

| 指标 | Prompt v4 | Prompt v5 |
| --- | ---: | ---: |
| 硬协议通过 | 6/9 | 9/9 |
| 冻结动作一致 | 3/9 | 6/9 |
| 平均完整返回时间 | 1.60 秒 | 1.02 秒 |
| P50 完整返回时间 | 1.46 秒 | 0.95 秒 |
| P90 完整返回时间 | 2.37 秒 | 1.75 秒 |
| 平均输入 token | 1,156.8 | 1,362.7 |
| 平均输出 token | 203.4 | 123.8 |

调用均为 DeepSeek V4 Flash 非思考模式、temperature 0、零自动重试。延迟差异只来自各自一次 API 调用，样本量较小，不能解释为稳定的速度提升。

## 已确认的协议修复

- `LT-ESC-003`：不再把目标句已有英文列为 `sourceZh`。
- `LT-ESC-016`：不再把一个顶层中文片段拆成多个顶层 item。
- `LT-ESC-018`：不再把目标句已有英文改写成中文后新增 item。
