# v6 控制权外移实验

## 实验问题

不迁移框架，只把可确定的产品决策移出模型，能否减少 LinguaType 对模型指令遵从性的依赖？

## 变量

- 保持不变：冻结 v4 case、题目、全文、目标句、DeepSeek V4 Flash 非思考模式、temperature 0、零自动重试、最终 v4 用户界面结构。
- 改变一：本地锁定 `sourceZh`，模型不再返回该字段。
- 改变二：本地规则给出 `requiredAction`，模型不再选择帮助方式。
- 改变三：模型只返回英文表达或中文支架与隐藏英文；后端把模型内容合并进本地结构。

## 临时路由规则

按 `sourceZh` 中的中文字符数量：

- 10 个及以下：`provide_expression`。
- 11 个及以上：`offer_scaffolds`。

该规则在现有冻结 v4 的 25 个顶层片段上恰好与 14 个直接项、11 个复杂项全部一致。它很可能受当前人工设计样本分布影响，只用于验证“产品侧锁定动作”的控制架构，不能写成真实场景通用规律；后续必须用真实用户卡点验证并修订。

## 成功标准

1. 9 个定向 case 不出现顶层片段、动作或 item 数量漂移。
2. 最终合并结果继续通过冻结 v4 协议校验。
3. 零自动重试，记录一次完整返回时间。
4. 协议通过后仍由用户人工判断英文和支架质量，不把结构稳定写成效果提升。
