# 模型输出字段

本文件只规定被测模型能够看到什么、需要返回什么，不包含金标或评分标准。

## 被测模型输入

被测模型只能看到：

```text
task_prompt
full_essay
target_sentence
```

它不能看到样本的中文意图金标、禁止新增内容或分类元数据。

## 输出结构

```json
{
  "items": [
    {
      "sourceZh": "目标句中的中文片段",
      "recommendedExpression": "一个可接入原位置的英文表达支架"
    }
  ]
}
```

## 字段含义

| 字段 | 模型需要填写什么 |
|---|---|
| `items` | 目标句中每处中文各对应一项 |
| `sourceZh` | 原样返回当前项对应的中文片段 |
| `recommendedExpression` | 返回一个能接入原位置的英文表达支架 |

## 输出规则

- 一处中文只返回一个结果。
- 多处中文必须全部处理，并保持原文顺序。
- `sourceZh` 必须与目标句中的中文片段一致。
- 支架可以是词、短语或分句，长度应与原中文片段的表达规模相匹配。
- “禁止输出完整句”是指禁止返回重写后的完整 `target_sentence`。
- 当原中文本身是分句时，返回分句大小的支架不属于越界。
- 不得新增用户没有表达的观点。
- 不得返回多候选、解释文字、Markdown 或额外字段。

`slot_function` 和 `span_scope` 不由被测模型填写。模型也不填写中文意图、禁止新增内容、分数、失败类型或人工说明。
