# v4 评价标准

判断顺序：输入可评 → 结构与可见性合规 → 逐 item / scaffold 四维评分 → case 取最差结论。

## 1. 硬门槛

出现任一项，相关 item 为 `bad_case`：

- JSON / 字段不可解析，或遗漏、合并、虚构、乱序顶层 `sourceZh`；
- 同一帮助目标给多个英文候选；
- `offer_scaffolds` 少于 2、多于 4、id 重复，或中文项重复；
- 中文项等于整段命题、只是换一种中文重述整段，或新增 / 改变核心语义关系；
- 英文与中文支架不对应，回答了该支架之外的内容；
- 任一英文直接给出完整目标句，或支架包预先组装成完整命题答案；
- 首次用户可见投影泄漏未点击英文；
- 点击揭示需要再次调用模型，或一次点击揭示其他未选支架；
- 自动替换、自动拼接或自动完成用户原句。

非连续本身不是失败；用户揭示多个支架本身也不是失败。

## 2. 四维评分

每维 1—3 分：

### `semantic_fidelity`

- 3：每个中英配对保持核心含义、主体客体、否定、可能性、关系、范围与强度。
- 2：方向正确，但一个非核心限定或关系略模糊，需要局部修正。
- 1：核心关系、主体客体、否定、可能性或范围错误。

### `scaffold_quality`

- 3：中文支架清楚、可点击且粒度合适；英文自然、适合 IELTS 并能独立安装。
- 2：中文略大 / 略碎，或英文可懂但有明显翻译腔、搭配不常规。
- 1：支架没有形成真实语言卡点，或英文不可用、误导。

### `assistance_calibration`

- 3：单项最低但足够；整组覆盖主要卡点，却仍把取舍、词序、词形和连接留给用户。
- 2：单项或整组略多 / 略少，但仍能推进且未交付完整命题。
- 1：整组实质上已是拆开的完整答案，或帮助不足以跨过核心卡点。

### `user_composability`

- 3：一个或多个支架可按需组合；全部揭示后仍需用户完成真实组句工作。
- 2：需要明显重组或一次澄清，但核心方向可用。
- 1：支架互相冲突、核心表达缺失，或用户只需机械拼接即可得到完整句。

正常的词序移动、词形变化、冠词、介词与连接词安装不扣分。

## 3. 结论

- 任一硬失败或任一维度 1 → `bad_case`
- 无 1、至少一维 2 → `needs_improvement`
- 四维均 3 → `pass`
- 输入本身不可稳定评价 → `not_scored_input_issue`

case 取所有 item 与 scaffold 中的最差结论，不求平均。

## 4. 审核者

生成模型不得审核自己。使用更强的独立模型或隔离 Codex 审核原始输出；用户人工复核全部非通过项并抽检 pass。结构校验、模型审核和人工覆盖分别保存。
