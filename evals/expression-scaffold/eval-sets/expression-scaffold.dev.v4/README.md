# expression-scaffold.dev.v4

状态：`frozen`。冻结日期：2026-08-24。

v4 只改变交互与输出契约，不把 v3 数字迁移成新版本结论。

## 核心变化

复杂中文片段不再经历第二次模型调用。模型在首次请求中同时生成：

- 2—4 个可点击的中文语义支架；
- 每个支架对应的一个英文表达。

界面首次只展示中文支架。用户点击后，由本地状态揭示已经随首轮结果返回的英文；可以依次选择多个，已揭示内容保持可见。揭示、取消或再次点击都不调用模型。

```text
20 个 case，各调用模型一次
→ 直接项立即显示一个英文表达
→ 复杂项先显示 2—4 个中文支架
→ 用户逐个点击，本地揭示对应英文
→ 用户自行组合、变形并完成句子
```

## 相对 v3 的边界变化

- 保留 14 个直接项、11 个分层项及“可追溯但不必连续”的语义规则。
- 删除 `selected_focus` 阶段、选择策略和第二次模型等待。
- 允许用户揭示多个支架；“非代写”由支架粒度和禁止整句组装保证，不再由“只能选一个”保证。
- 模型原始输出属于内部支架包；用户可见投影不得提前暴露未选择英文。

冻结入口为 `freeze-manifest.json`。Prompt 仍是独立实验变量，不纳入 eval-set 冻结指纹。
