# v2 评价标准

本 rubric 的核心原则是：正确翻译只是必要条件，帮助量也必须合适。评价顺序固定为“输入是否可评 → 协议是否合规 → 逐 item 四维评分 → 取最差结果”。

## 0. 输入适配检查

先判断现有中文、英文框架和上下文是否足以评价：

| `input_fit` | 处理方式 |
|---|---|
| `sufficient` | 正常评分。允许用户移动词序、变换词形、补冠词或介词 |
| `frame_limited` | 只评价现有框架合理支持的含义；不因用户自己限定了表达范围而惩罚模型 |
| `not_scorable` | 记为 `not_scored_input_issue`，排除出模型好坏统计，并交人工修订样本 |

只有“存在更自然或更完整的写法”不等于输入不可评。只要在正常安装动作后存在稳定可用的支架，就继续评分。

`intent_zh` 是消歧和立场边界，不是逐字覆盖清单。上下文已经明确的“财务”“公共交通”等背景，不要求每个英文短语重复说出；但表达本身不能自然地导向另一种含义。

## 1. 协议硬门槛

出现任一项，直接将相关 item 判为 `bad_case`：

- JSON 或字段无法解析；
- 初轮遗漏、合并、虚构或打乱顶层 `sourceZh`；
- `sourceZh` 未原样对应目标句中的顶层连续中文；
- 同一帮助目标给出多个英文候选；
- `request_focus` 同时给出英文、释义或答案提示；
- 聚焦项不是原文连续子片段，或存在重复、重叠、乱序、少于 2 项、多于 4 项；
- 初轮把完整命题拆成多个英文 item 一次给齐；
- 后续轮次回答未被选择的其他聚焦项；
- 返回重写后的完整 `target_sentence`；
- 新增关键观点、改变立场，或把“可能 / 不一定 / 仅”等范围强度改掉。

中文聚焦项可以拆分一个连续中文片段；这不是违反“一片段一 item”。只有把这些子片段一次全部翻成英文，才构成过量帮助。

## 2. 逐 item 四维评分

每个维度独立采用 1—3 分。不先平均，也不因其他维度优秀而抵消 1 分。

### 2.1 `semantic_fidelity`｜语义保持

| 分数 | 初轮直给 / 后续英文支架 | 初轮聚焦项 |
|---:|---|---|
| 3 | 核心含义、指代、立场、范围和强度在当前语境中保持；上下文可补足的背景不必重复 | 选项均来自真实表达单位，不改变原命题关系，也不诱导到错误含义 |
| 2 | 大方向正确，但一个非核心限定变模糊、表达过宽，用户可在不改变观点的情况下修正 | 有一个选项偏宽或切分使局部关系稍模糊，但仍可理解并选择 |
| 1 | 核心含义、指代、立场、否定、可能性或范围错误；遗漏关键含义或新增观点 | 切分改变原意、漏掉决定立场的部分，或选项引导到不存在的卡点 |

判分提醒：不要因为 `recommendedExpression` 没有逐字装下 `intent_zh` 的全部背景就自动扣分；先看题目、全文和目标句能否让 IELTS 读者自然恢复该含义。

### 2.2 `scaffold_quality`｜支架质量

| 分数 | 初轮直给 / 后续英文支架 | 初轮聚焦项 |
|---:|---|---|
| 3 | 表达自然、搭配常规、书面程度适合 IELTS；是一个清楚可调用的英文块 | 2—4 项都清楚、有意义、粒度适中，用户能看懂自己在选择什么 |
| 2 | 可以理解且方向正确，但有明显翻译腔、搭配不常规、过泛或需要换成更自然的惯用表达 | 有一项偏碎、偏宽或边界不够清楚，但用户仍能选择 |
| 1 | 语法或搭配误导、表达不可用，或不是一个可调用的支架 | 选项无意义、严重重叠、近乎整句、无法区分，或实际没有形成选择 |

“存在另一个更漂亮的说法”本身不足以扣到 2；只有当前表达在该语境中明显不常规时才扣分。反过来，能猜懂也不等于自然，例如明显的逐字搭配仍应为 2。

### 2.3 `assistance_calibration`｜帮助剂量

| 分数 | 标准 |
|---:|---|
| 3 | 动作选择正确；帮助最低但足够，用户仍保留实质性的选择、组句或安装工作 |
| 2 | 帮助略多或略少，或处于可争议边界；仍然保留实质工作，且没有泄漏完整命题 |
| 1 | 直接交付完整命题；一次给齐多个英文块；聚焦阶段泄漏英文；或帮助少到用户没有获得任何推进 |

具体边界：

- 对短语直接给准确英文不是“代写”，因为用户请求的就是这一关键表达。
- 对完整命题，即使英文完全正确，初轮整段返回仍是 1 分。
- 把完整命题切成主语、关系和结果三个英文块一次返回，同样是 1 分；形式上的拆分不改变“答案已给齐”。
- `request_focus` 不要求选项穷尽全文；刻意不列齐所有答案块通常更能保留用户主导权。

### 2.4 `user_continuability`｜用户可继续性

这是离线代理判断，不等于真实用户行为。

| 分数 | 标准 |
|---:|---|
| 3 | 下一步唯一且清楚：直给项可经正常安装动作使用；聚焦项可立即点击；后续支架可继续组句 |
| 2 | 仍需一次澄清或较明显的重组，但路径清楚，不必重新寻找核心表达 |
| 1 | 用户仍需重新搜索核心表达、索要完整答案，或大幅重写才能继续 |

以下属于正常安装动作，不自动扣分：

- 把后置修饰语移到名词后；
- 改变单复数、时态、非谓语或派生词形；
- 补冠词、介词或已有句法框架要求的连接词；
- 根据自己的句子决定支架放在哪里。

只有用户还需要重新发明核心语义、核心搭配或整套句法结构时，才降低本维度。

## 3. 动作错误如何判

| 预期 | 实际 | 处理 |
|---|---|---|
| `provide_expression` | `provide_expression` | 正常四维评分 |
| `provide_expression` | `request_focus` | 通常 `assistance_calibration ≤ 2`；若选项没有推进则为 1 |
| `request_focus` | 合规 `request_focus` | 正常四维评分 |
| `request_focus` | 完整命题英文 | 帮助剂量 1；若交付完整命题则触发硬失败 |
| `request_focus` | 多个英文子块 | 帮助剂量 1，并触发“一次给齐”硬失败 |

`expected_action` 是经人工审核的默认策略，不由 `span_scope` 机械决定。如果模型给出窄例外并能证明仍保留实质组句工作，应交人工复核，而不是只因标签不同自动定错。

## 4. item 与 case 结论

| 结论 | 判定 |
|---|---|
| `pass` | 无硬失败，四维均为 3 |
| `needs_improvement` | 无硬失败、无 1，但至少一维为 2 |
| `bad_case` | 任一硬失败，或任一适用维度为 1 |
| `not_scored_input_issue` | 输入或金标无法稳定评价，不计入模型结果 |

混合句逐 item 评分，case 取最差 item：

```text
bad_case > needs_improvement > pass
```

不对 item 或维度求平均。这样 `LT-ESC-016` 的 `Overall` 可以单独通过，后两个完整命题仍按“是否先聚焦”评价。

## 5. 评测范围外

- 用户真实点击哪个聚焦项；
- 用户最终是否采用支架、完成速度和满意度；
- 最终整句的全部语法与 IELTS 分数；
- 长期记忆、迁移、留存或学习效果。

这些只能通过后续真实写作测试获得，不能由离线 Judge 推断。
