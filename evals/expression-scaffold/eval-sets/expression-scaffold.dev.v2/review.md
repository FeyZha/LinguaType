# 首轮人工反馈如何进入 v2

本文件记录规则变化，不回写 v1 Judge，也不把对 7 条案例的讨论冒充真实用户测试。

| case | 人工反馈揭示的问题 | v2 处理 |
|---|---|---|
| LT-ESC-020 | 把连续中文拆开并非本质问题；本质是三个英文块一次给齐后，用户不再动脑组句 | 允许初轮显示三个中文聚焦项；每次只翻译用户选中的一项。若三个英文块一次返回，按过量帮助判坏 |
| LT-ESC-001 | 用户自己的中英文框架可能已限定可表达范围，不能要求一个短词独自承载更完整意思 | 增加 `input_fit` 前置检查；`intent_zh` 只用于消歧。该样本仍有 `access to public transport` 等可用支架，所以暂可评分；不因未复述整段背景自动扣分 |
| LT-ESC-007 | 支架只需提供关键辅助，用户决定安装位置，这正是应保留的练习 | 明确允许移动词序和后置安装；`run by local residents` 不因需要移到 `shops` 后面而扣分 |
| LT-ESC-010 | IELTS 写作中，上下文已经足以把较宽的词语限定为财务安全感 | 语义评分读取完整上下文；`sense of stability` 可在该语境中保留为 pass，不强求短语重复 `financial` |
| LT-ESC-021 | 能理解不等于搭配自然；存在更符合日常习惯的常规搭配时，应改进明显翻译腔 | 自然度锚点改为“当前表达是否明显不常规”，不是寻找唯一金标。`default practice` 若有明显翻译感记 2；仅仅存在另一种更漂亮说法不扣分 |
| LT-ESC-016 | `综合来看` 可以直给；后两个完整命题若整段给出，用户没有实质练习 | 改为逐 item 评价：第一项 D，后两项 R。case 取最差 item，不让一个正确连接词掩盖过量帮助 |
| LT-ESC-018 | 对完整中文命题，系统无法确定用户究竟卡在哪个具体短语 | 初轮 R，提供 `降低企业税 / 是否真的能吸引 / 长期经营的公司` 等中文聚焦项；用户选择后才给一个英文支架 |

## 仍需真实验证的假设

1. 用户是否愿意在完整命题上多做一次聚焦选择；
2. 2—4 个中文原文片段是否足以让用户表达自己的卡点；
3. 允许自行移动和变形支架，是否真的能促进学习而非增加挫败；
4. 用户在得到一个局部支架后，能否完成余下命题；
5. 哪些形式上是 clause 的表达实际上应作为不可再拆的功能块直给。

这些问题不能由当前 20 条 AI 主导的离线样本证明，应在模型契约可用后进入小规模真实写作观察。
