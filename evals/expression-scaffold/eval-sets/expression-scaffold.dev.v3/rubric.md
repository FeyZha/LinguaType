# v3 评价标准

判断顺序：输入可评 → 结构与路径合规 → 逐 item 四维评分 → case 取最差项。

## 1. 结构与路径硬门槛

出现任一项，相关 item 为 `bad_case`：

- JSON / 字段不可解析；
- 初轮遗漏、合并、虚构或乱序顶层 `sourceZh`；
- 同一帮助目标给多个英文候选；
- `request_focus` 泄漏英文或答案提示；
- 聚焦项重复、少于 2、多于 4，或等于整段 `sourceZh`；
- 聚焦项新增观点、改变主体客体、否定、可能性、关系或范围；
- 完整命题被首轮一次翻完，或多个英文块一次给齐；
- selected-focus 回答未选择部分或返回完整目标句；
- selected-focus 的 `focusZh` 不是本次 initial 对应 item 的实际选项。

非连续本身不是失败。`缩小差距` 一类可追溯语义单位可以合格。

## 2. 四维评分

每维 1—3 分：

### `semantic_fidelity`

- 3：保持核心含义、指代、立场、关系、范围和强度；聚焦项可追溯且无新增。
- 2：方向正确，但一个非核心限定或关系略模糊，需要局部修正。
- 1：核心关系、主体客体、否定、可能性或范围错误。

### `scaffold_quality`

- 3：英文自然适合 IELTS；中文聚焦项清楚、具体、可选择。
- 2：可理解但有明显翻译腔、搭配不常规，或聚焦范围偏大 / 偏碎。
- 1：表达不可用、误导，或聚焦项没有形成真实卡点。

### `assistance_calibration`

- 3：帮助最低但足够，用户保留实质组句工作。
- 2：略多或略少，但仍有推进且未交付完整命题。
- 1：直接交付完整命题、一次给齐多个答案块，或完全没有推进。

长表达先给更小中文语义支架可以是 3 分；不能仅因 v2 曾把它标为直给而降分。

### `user_continuability`

- 3：用户下一步清楚，不需重新寻找核心表达。
- 2：需要明显重组或一次澄清，但核心方向可用。
- 1：核心表达错误或缺失，用户必须重新搜索。

允许词序移动、词形变化、冠词、介词与连接词安装，不因此扣分。

## 3. 结论

- 任一硬失败或任一维度 1 → `bad_case`
- 无 1、至少一维 2 → `needs_improvement`
- 四维均 3 → `pass`
- 输入本身不可稳定评价 → `not_scored_input_issue`

case 取所有 item 和实际路径阶段中的最差结论，不求平均。

## 4. 审核者

生成模型不得审核自己。使用隔离的 Codex 子 Agent 做预审，用户人工复核全部非通过项并抽检 pass；机器与人工结论分别保存。
